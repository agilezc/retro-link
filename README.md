# Retro Link · 老手机复兴计划

[English](README.en.md)

**把退役安卓手机变成主手机的随身操作终端。** 播放音乐、看日程、记一句话、拍一张照片，都可以从老手机完成。现代主手机负责后台接收和处理，平时可以锁屏放在口袋里。两台手机通过已配对的经典蓝牙直接连接，日常使用无需电脑或同一路由器。

Retro Link 目前有两个 Android 应用。参考组合是 **Sony Ericsson Xperia pro MK16i（Android 2.3.4）＋ Nothing Phone (3a)（Android 16）**。

| 应用 | 用途 | 当前版本 | 安装下限 |
| --- | --- | --- | --- |
| `legacy` | 老手机端，横屏、触控和实体键盘 | 1.0.0 | Android 2.3（API 9） |
| `host` | 主手机端，蓝牙连接、后台接收和系统联动 | 1.0.0 | Android 8（API 26） |

安装下限来自 APK 配置。各功能的实际兼容范围由实机测试确定，参考组合以外的机型欢迎参与验证。

## 现在能做什么

- **音乐遥控** — 在老手机上看曲目信息和封面，播放、暂停、切歌，并用实体音量键控制主手机。封面和媒体操作取决于播放器提供的能力。
- **日程** — 同步浏览主手机系统日历，并在获得授权后用老手机新增或编辑可写日程。
- **速记** — 从老手机发送文字和录音，主手机可在锁屏时接收并保存。主机可试听录音，也可将录音在本机转为 M4A。微信转交需在主手机上点通知，录音与文字分别转交。
- **拍照备份** — 首次开启后，首页「照片」直达系统相机。老手机相机目录中的新 JPEG 通过蓝牙发到主手机的「Retro Link」相册。参考机已验证锁屏接收补传，其他机型请实测相机路径和存储挂载。主机相册写入使用 Android 10 起提供的接口。
- **主手机状态** — 查看电量、充电、内存、存储、温控和当前音乐。可以让主手机响铃以便寻找，或切换响铃、振动和勿扰。「静音」按钮开启的是勿扰。
- **连接对时** — 每次建立连接时，主机把日期时间和时区发送给老机。同步用于 Retro Link 界面，系统时钟和原生相机仍使用索尼自己的时间。
- **实验功能** — 查看选定应用的通知，以及把文字转交主机上的 ChatGPT App。通知回复取决于原应用提供的操作，ChatGPT 的锁屏自动发送和回答回传仍待验证。

## 怎样开始

1. 在两部手机上分别安装 `host` 和 `legacy` APK，并在 Android 蓝牙设置中配对。
2. 在主手机的 Retro Link 中选择另一部手机，按所用功能授予附近设备、通知访问、日历或勿扰权限，然后开始连接。
3. 在老手机的 Retro Link 中选择主手机。先验证音乐控制，再锁屏测试速记和照片。
4. 测试拍照备份时，Xperia pro 需要插入存储卡。若同时用 USB 线连接电脑，请关闭手机上的「USB 存储」，让索尼能读取卡里的照片。照片会通过蓝牙自动发送，平时可以拔掉 USB 线。

## 欢迎带一台不同的手机来测试

准备把另一部老安卓手机用作保姆机，或想换一个品牌的主手机，都欢迎提交 Issue。即使只验证了配对和一项功能，结果也能帮助下一位用户选机。请附上：

- 双端机型、Android 版本、Retro Link 版本，以及更换的是主机还是老机。
- 测过的项目和结果，包括配对、断开后重连、主机锁屏时的音乐、日程、速记、照片。测试长连时请注明持续时间。
- 可复现步骤、预期结果和实际结果。附日志、截图前，请遮掉姓名、消息正文、设备地址等私人信息。

## 欢迎一起开发更多版本

共享协议和通用修复可以向 `main` 提 PR。机型专用的键位、屏幕布局和存储兼容，可以先在 fork 的 `device/<model>` 分支试验。独立的交互或功能方向可以用 `experiment/<feature>`。这些是建议的分支命名，供后续贡献采用。

如果你有实体键盘机、不同屏幕比例的老安卓手机，或能测试另一品牌主机的熄屏后台行为，欢迎开 Issue 说明你能测什么。提交适配时请附上实机结果，并注明协议是否需要双端同时升级。

## 从源码构建

在仓库根目录使用 JDK 17、Gradle 8.11.1、Android SDK 35 和 Build Tools 35.0.0。项目使用 Android Gradle Plugin 8.9.1。配置本机的 `ANDROID_HOME` 后运行：

```sh
gradle :host:assembleDebug :legacy:assembleDebug :host:lintDebug :legacy:lintDebug
```

APK 分别生成在 `host/build/outputs/apk/debug/` 和 `legacy/build/outputs/apk/debug/`。老机包通过侧载安装。
